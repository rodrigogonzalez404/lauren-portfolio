**re-run `python3 _src/build.py`** so that the query string changes. If you don't, visitors keep the old cached file.

**⚠ `images.py` wipes `assets/img/` before it rebuilds.** If one source is missing, the run dies part-way and leaves the
site without images. Never run it on a checkout you might commit unless the full zip is unpacked and `render_pages.sh`
has been run. For a single-case change, call the specific generator instead. Examples:
`python3 -c "import sys;sys.path.insert(0,'_src');import flyer_sheets;flyer_sheets.main()"`, or `madison_card.main()`,
`bp_assets.cards()` (add `_src/bigpink` to the path). Then run `build.py`. The simplest safe path for most edits is to
**edit copy in `content.py` / drop replacement images into `assets/img/<slug>/` with the same names, then run `build.py`**.

### What Claude cannot reproduce even with the zip
- **New Ceros captures.** They were taken from a Ceros preview URL that must not be linked, and that URL isn't recorded here
  on purpose. If Big Pink screens change, Rodrigo must supply new captures (1600×900).
- **Lauren's original design files** (InDesign/Figma). Only PDFs and exports exist. Higher-res Nomad imagery has the same problem: the Nomad card
  source is only ~1120 px wide.
- **The excluded-project PDFs and the 745 MB of page renders** are not in the zip. The renders are regenerable, but byte-exact
  matches depend on the poppler version (25.03 was used). Blur boxes are fractions of the page, so small raster differences are harmless.
- The exact screenshot-level look of `mk/scenes/` results depends on OpenCV 5.0.0 and Pillow 13.0.0. Other versions should be visually identical.

## 7. Design system and components

- **Page background** `--paper` **#F2F2F2** (unchanged; switching it to stone is pending). Ink #0F0F0F, body #29292B, muted #69696B,
  lines #BFBFBF. 8-column grid (24 px gutters, 48 px margins at 1440; 16 px on mobile). Breakpoints 960/820/640.
  Section rhythm tokens `--sec`, `--s96…`; case tokens `--cs` 128 / `--cn` 80.
- **Fonts:** Geist (UI/headings/body), PT Mono (uppercase labels like `[01]`). Open Sans only on The Grid and Cabin only on Big Pink. Arrow
  glyphs in viewer hints use Geist (`.kb`) because PT Mono lacks ← →.
- **Mockup surface: pale stone #ECEAE6** (`palette.CREAM`), **with real texture and context**. Rodrigo: "I want it to look pale
  stone but with texture and context." Colour-grade scene backdrops only. **Never denoise, blur or smooth** them (the smoothed
  version was rejected as "blurred"). It replaced the cream #D2CEC8, which "looked tanned". `flyer_mockups.surface()` = stone with a neutral
  grain/mottle and a colourless light falloff. Shadows are neutral grey multiply layers.
- **Flip-book desk:** dark charcoal procedural wood (`ui/desk-charcoal.jpg`, `.fb-stage`). It is not part of the stone change.

**Reusable components**
- **Flip-book** (Nomad, Madison, Pacific): StPageFlip on the charcoal desk. Each book has its own `#fb-book data-w/data-h`. `data-total` + `data-pg` show
  printed page numbers. Black HTML spread for omitted financials (Madison).
- **iPad viewer** `ipad_viewer(slug, title, files, r, note, label)` (Kress, PDX, Leftbank, Springwood, Mauzey): CSS-drawn landscape
  iPad on textured stone. It supports drag/swipe, clicking the screen halves, arrows, ← → keys, dots, a "Page 01 / NN" counter, lazy `data-src`, and
  cross-fade under reduced motion. A file entry `('CONF', 'section text')` renders the black confidential screen.
- **Laptop viewer** = `ipad_viewer(..., device='laptop')`, 16:9 (Big Pink), with the same interactions.
- **Sheet stack** `sheet_stack()` (legacy, CSS `.ss-*`), no longer used on a case page.
- **Confidential screens/spreads:** black, "Confidential — financial information omitted".
